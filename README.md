# Sentinel Analytics

Анализ продаж магазина охранных систем Sentinel за 2026 год.  
**HSE minor project, 2026**

## Стек
- Python 3.13
- SQL (SQLite)
- pandas, matplotlib, seaborn
- Jupyter Notebook

## Файлы
- `sentinel.db` — база данных (8 таблиц, ~800 заказов)
- `analysis.ipynb` — 5 аналитических блоков с визуализациями
